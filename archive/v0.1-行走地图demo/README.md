# 斗罗大陆 · v0.1 行走地图 Demo

> 这是大世界重构前的存档版本：200×200 岛屿 + 圣魂村 + 游泳 + 天气系统。
> 双击 `index.html` 即可离线游玩。

## 操作
- WASD / 方向键：移动（水里自动游泳，Shift 加速）
- 开场点击「开始探索」

## 内容清单
- 噪声生成的岛屿大陆（每次刷新固定种子）
- 圣魂村：城墙/城门/大街/民居/广场喷泉
- 水面：AI 天空倒影（世界锚定云影）+ 岸线泡沫
- 天气循环：晴 → 雨（雨丝 + 水面涟漪 + 陆地水珠溅落）
- 游泳系统：AI 划水贴图、四方向、V 字尾流
- 性能：chunk 分块缓存渲染
